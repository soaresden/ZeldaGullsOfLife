# Le Phare Éteint (donjon 1), groupe 4, décor 36 (pierre du 1er donjon d'Ages).
# Grandes salles : 11 lignes de 15 briques. Voir out/catalog/decor_36.png (tools/render_room.py).
#
# Briques : b8 b0 b9 / b3 b1 / ba b2 bb = murs ; a0 = sol ; a3 a4 = mosaïque ;
#   passage entre deux salles : un trou dans le mur (a0, du sol), comme la salle de l'essence d'Ages
#   (bc-bf sont des portes pleines : Link ne passe pas) ;
#   volets (fermés tant qu'il reste des ennemis, ou que les torches sont éteintes) : 78 79 7a 7b
#   (haut, droite, bas, gauche ; c'est l'objet INTERAC_DOOR_CONTROLLER $1e qui les ouvre) ;
#   porte à petite clé : 70 71 72 73 ; porte du boss : 74 75 76 77 ; 1e = bloc à serrure ;
#   08 = torche éteinte (la Lanterne l'allume) ; 68 / 69 = mur fissuré (à droite / à gauche) que
#   la flamme de la Lanterne fait brûler ; 0a = cristal à frapper à l'épée ; 0c = bouton au sol ;
#   2a = statue qu'on pousse (autant qu'on veut) ; 1c = bloc qu'on pousse une fois ; 26 27 = statues ;
#   f5 = trou ; f1 = coffre (contenu : data/ages/chestData.s, un coffre par salle) ; 10 = pot ;
#   e0-e6 = l'arche de l'entrée.
# Après « decor 36 » : « sombre » = salle dans le noir tant que ses torches sont éteintes ;
#   « boss » = la salle du boss (sur la mini-carte).
# La mini-carte (portes, salle sombre) est calculée par tools/make_rooms.py.
#
# Plan (dungeon01LayoutPhare, un seul étage, tout en hauteur comme un phare) :

#                                   (3,0) la lumière (essence, 4:11 d'Ages)

#               (2,2) balcon ouest — (3,2) la galerie — (4,2) balcon est
#                                   (3,3) la tour, haut : 3 torches -> une petite clé
#                                   (3,4) la tour, milieu : le mini-boss (Ghini géant)
#                                   (3,5) la tour, bas : un bloc à serrure, 2 torches
# (1,6) la douve — (2,6) la garde — (3,6) le pied du phare — (4,6) la Lanterne — (5,6) le cristal
#               (2,7) les Zols — (3,7) l'entrée — (4,7) la statue

# la porte à clé -> la Lanterne ; au pied du phare, les 2 torches ouvrent la tour, mais il faut une
# 2e clé : brûler le mur fissuré de la salle de la Lanterne, frapper le cristal (un pont apparaît

# la porte à clé du balcon ouest, la statue sur le bouton (la clé du boss) ; le balcon est (100
